TORNEO RELÁMPAGO SAN JOSÉ DEL GACAL
====================================

Archivos:
- index.html: página principal
- sorteo.html: sorteo y grupos
- posiciones.html: tablas de posiciones y clasificación
- calendario.html: próximos partidos
- resultados.html: marcadores registrados
- envivo.html: enlaces de transmisión
- admin.html: panel de administración
- estilos.css: diseño visual
- firebase.js: conexión a Firebase
- app.js: lógica del torneo

IMPORTANTE:
1. Mantén todos estos archivos juntos en la misma carpeta.
2. Publica la carpeta raíz del repositorio en GitHub Pages.
3. El proyecto utiliza Firebase Realtime Database y Firebase Authentication.
4. Conserva las reglas de Firebase con lectura pública y escritura limitada
   al UID administrador configurado en firebase.js.
5. El formato de grupos implementado utiliza dos grupos (A y B).
6. La generación de fixture produce los partidos de fase regular. En eliminación
   directa genera la primera ronda; las siguientes rondas deben completarse
   según los resultados.
7. No compartas contraseñas ni credenciales de administrador.

Para publicar cambios desde la terminal:
  git add .
  git commit -m "Actualizacion del torneo"
  git push origin main
