TORNEO RELÁMPAGO SAN JOSÉ DEL GACAL

CONTENIDO
- index.html: página de inicio
- sorteo.html: grupos y sorteo
- posiciones.html: tablas de posiciones
- calendario.html: próximos partidos
- resultados.html: resultados registrados
- envivo.html: transmisión
- admin.html: panel de administración e inicio de sesión
- estilos.css: diseño visual
- firebase.js: configuración de Firebase y UID autorizado
- app.js: lógica de la aplicación

INSTALACIÓN / ACTUALIZACIÓN
1. Haz una copia de seguridad de la carpeta actual del proyecto.
2. Extrae esta carpeta ZIP.
3. Copia los archivos de esta carpeta sobre la carpeta original del repositorio GitHub.
4. Acepta reemplazar los archivos con el mismo nombre.
5. En Visual Studio Code abre Terminal y ejecuta:
   git add .
   git commit -m "Corrige acceso y funciones del torneo"
   git push origin main
6. Espera a que GitHub Pages publique y recarga el sitio con Ctrl+F5.

IMPORTANTE SOBRE EL ACCESO ADMINISTRADOR
- Este paquete conserva el UID administrador configurado previamente en firebase.js.
- El correo y la contraseña deben pertenecer a un usuario creado en Firebase Authentication.
- El UID real de ese usuario debe coincidir exactamente con ADMIN_UID en firebase.js.
- Si no coincide, el sistema mostrará el UID detectado y rechazará el acceso. No se debe quitar esta comprobación ni abrir los permisos de escritura.
- En Firebase Console > Authentication > Sign-in method, habilita Correo electrónico/Contraseña.
- En Authentication > Settings > Authorized domains, verifica que esté agregado:
  elkincastillo124-web.github.io
- No compartas tu contraseña ni claves privadas.

NOTA DE PRUEBAS
Se verificó la sintaxis JavaScript con Node.js. La autenticación real depende de la configuración y del usuario existente en tu proyecto Firebase; no se puede confirmar desde este paquete sin iniciar sesión en tu cuenta.
